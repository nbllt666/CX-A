# CX-A

> 轻量、开箱即用的桌面 AI：聊天、桌宠、记忆、语音，都跑在自己的电脑上。

---

## 它是谁

平时，它是陪你说话、记得你每一件小事的伙伴；

点一下按钮，它也能变成替你打理「分身们」和家里那台重度实例的管理者。

**不用显卡、装好即用、开箱就能聊**——重活交给云端的大脑子，而「听你说、记住你、用声音回你」这些事，都在你的电脑上悄悄完成。

---

## 它会什么

| 能力 | 说明 |
|------|------|
| **随时可以聊** | 文字、语音都行；点一下麦克风它就一直听着，你说完它接话，也能切成「边说边聊」的全双工（它说话时你开口就打断）；回复时桌宠会动嘴、带表情，聊过的内容自动存下来，重启不丢 |
| **记性好** | 记得你的偏好、重要的事、说过的小细节，越陪越懂你；重要的事它还会自己整理成长期记忆；也可以直接跟它说「帮我记一下」「找找那天聊过的」，它来替你记和找 |
| **会干活（可选）** | 经你授权后，可以帮你点屏幕、敲键盘、执行指令（**默认关闭，随时可撤销**）；也能让它看懂你共享的屏幕画面（画面只在本机理解） |
| **一体两面** | 默认是陪伴者；点一下就能切到管理者，打理它自己的分身与远端实例 |
| **好看** | 轻薄玻璃质感 + 二次元审美；开箱即有一只**3D 小宠物（VRM 模型）**趴在桌面上（默认开启，随时可关）；想换口味？换成你喜欢的模型给它换装，它的表情还会跟着聊天情绪变化 |
| **断网不哑巴** | 开启本地模式后，没网也能陪你聊，还能看图（需另下载本地小模型，约 3～7GB，四档可选） |

## 开箱即用

- ❌ 不需要显卡
- ✅ **独立安装程序**一步装好——语音（朗读与麦克风）、看图与记忆引擎全内置，装完即用
- ✅ 首次启动有向导：它会先看看你的电脑跑得动什么 → 推荐一套合适的设置 → 选一个云端服务商 → 填入你的「云端钥匙」→ 开聊；赶时间的话，直接点「就用推荐的」一步到位
- ✅ 下载会先问你走哪条线路：**国内（魔塔，推荐）**（下载更快更稳）或**海外（HuggingFace）**；想让它断网也能陪你聊，可以顺手把本地小模型一起下好
- ✅ 默认自带官方音色，不折腾；安装程序版连朗读、麦克风、「看图」与「断网也能聊」都开箱可用（本地小模型由向导按档位下载）
- ✅ 装好启动后，桌面上会多出一只 3D 小宠物陪你（默认开启，设置页里可随时关掉）

## 快速开始

1. **安装**：双击**独立安装程序**（`CX-A-Setup-<版本>.exe`）安装（默认装在用户目录，无需管理员），安装过程会自动装好**语音**（朗读与麦克风）、**看图**与**记忆引擎**，装完即用；卸载走系统「应用和功能」即可。
2. **首次引导**：跟随向导走完四小步——
   1. **看看你的电脑**：它会读一下你的内存、显卡和硬盘，告诉你「跑得动本地小模型」还是「更适合把思考交给云端」，并给一个推荐配置，你可以直接用，也可以自己改；
   2. **选云端服务商**：挑一个你信得过的，填入「云端钥匙」（在服务商官网申请即可）；暂时没有也能先跳过，以后再补；
   3. **选下载线路**：就一个问题——**国内（魔塔，推荐）**还是**海外（HuggingFace）**；选了国内，依赖和模型都从国内站点拿，一般更快更稳；
   4. **要不要现在就下本地小模型**：想让它断网也能聊就现在下（会显示进度，随时能停），不想下就点「以后再说」。
3. **开聊**：直接输入文字，或点一下麦克风开启语音会话——它就一直听着，你说完自动接话；想在它说话时随时插话，到设置里把语音交互换成「全双工」。
4. **（可选）换个性格**：到设置页的「角色人设」卡，把它的人设改成你喜欢的样子，下一次对话就生效。
5. **（可选）交付电脑**：到设置页手动打开「电脑控制」；涉及电脑控制的高危操作前，它会先问你一句。
6. **（可选）想再跑一遍引导**：到设置页点「重新跑一遍新手引导」，可以重新挑下载线路、换模型大小，或者补下本地小模型。

> 想要更懂你？聊得越多，它记得越多。

## 隐私与安全

- 你的记忆**只存在本机**（除非你允许云端帮忙做深度整理）。
- 屏幕共享的画面**只在本机理解**，不会上传到任何地方。
- 电脑控制**默认关闭**，必须你显式开启；高危操作执行前会先征求你同意，并留操作记录。
- 云端只负责「思考」，听与说都在本机完成。
- 你填的云端钥匙经加密保存在本地，不会上传。

## 常见问题

**Q：没显卡能跑吗？**
A：能。它把「想」交给云端，把「陪伴」留在本地；向导会按你的电脑给出合适的建议。

**Q：不想用云端可以吗？**
A：可以在设置里开启本地模式（需另下载本地小模型）；网络断了也有兜底，不会突然闭嘴。

**Q：下载老是失败、特别慢怎么办？**
A：在向导（或设置页的「重新跑一遍新手引导」）里把下载线路换成**国内（魔塔）**，依赖和模型都从国内站点拿，一般就顺畅了。下载中断也没关系，下次接着下，已经下好的部分不会白费。

**Q：本地小模型该下多大的？**
A：向导会按你的电脑推荐一档，直接用推荐的最省心。它提供四档，从约 2.9GB（最轻巧）到约 6.6GB（效果最好）：**电脑比较轻巧就选小的那档**，够用且不占地方；**内存和显卡都宽裕就选大的**，回答质量更好。默认推荐的那档约 2.9GB，内存 8GB 的普通家用电脑都带得动。四档都自带「看图」能力（会另下约 0.9GB 的看图组件）。

**Q：当时跳过了下载，现在想让它断网也能聊？**
A：到设置页点「重新跑一遍新手引导」，选好大小点下载就行；也可以直接开本地模式，它会在需要时提醒你补下。

**Q：管理面是干嘛的？**
A：CX-A 本身就是管理面——负责打理 CX-O 实例群（语音、自主性、直播、配置、Agent、调优等运行时）。管理面刻意不放在界面里，只以 API 形态存在：CX-O 实例会主动把地址报上门（同机自动注册），CX-A 维护实例台账并统一转发治理指令（`/api/fleet/*`）。外部管理程序这样接入：启动后读安装目录 `logs\api_token.json` 拿当次令牌 → 调 `http://127.0.0.1:8600` 的管理端点即可。不在同一台电脑的 CX-O 实例走手动登记（`POST /api/fleet/instances`）；实例注销后若它还在上报，会重新出现在台账里。普通用户用不到管理面，完全不影响日常使用。

**Q：它能控制我的电脑，安全吗？**
A：默认完全关闭。只有你在设置里手动打开，且每一个高危指令都会先弹窗问你；任何时候可以在设置关闭，立即收回能力。
