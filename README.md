# CX-A · 你的赛博伴侣

> 把「有显卡才养得起的赛博老婆」轻量化成**谁都装得起的随身灵魂**。
> 心里装着你的陪伴者，一转身也是靠谱的管理者。

---

## 它是谁

平时，它是陪你说话、记得你每一件小事的伙伴；

点一下按钮，它也能变成替你打理「分身们」和家里那台重度实例的管理者。

**不用显卡、解压即用、开箱就能聊**——重活交给云端的大脑子，而「听你说、记住你、用声音回你」这些事，都在你的电脑上悄悄完成。

---

## 它会什么

| 能力 | 说明 |
|------|------|
| **随时可以聊** | 文字、语音都行；你一开口它就接话，自带官方音色（CX-OPEN），开箱即用 |
| **记性好** | 记得你的偏好、重要的事、说过的小细节，越陪越懂你；重要的事它还会自己整理成长期记忆 |
| **会干活（可选）** | 经你授权后，可以帮你点屏幕、敲键盘、执行指令（**默认关闭，随时可撤销**） |
| **一体两面** | 默认是陪伴者；点一下就能切到管理者，打理它自己的分身与远端实例 |
| **好看** | 轻薄玻璃质感 + 二次元审美；开箱即有一只**3D 小宠物（VRM 模型）**趴在桌面上（默认开启，随时可关） |
| **断网不哑巴** | 开启本地模式后，没网也能陪你聊（需另下载本地小模型，约 0.5～4.7GB，四档可选） |

## 开箱即用

- ❌ 不需要显卡
- ✅ 两种拿法：**便携包**解压即用（免安装）；或**独立安装程序**一步装好——语音引擎与本地推理运行时都会一并装进安装目录，装完即用
- ✅ 首次启动有向导：它会先看看你的电脑跑得动什么 → 推荐一套合适的设置 → 选一个云端服务商 → 填入你的「云端钥匙」→ 开聊
- ✅ 下载会先问你走哪条线路：**国内（魔塔，推荐）**（下载更快更稳）或**海外（HuggingFace）**；想让它断网也能陪你聊，可以顺手把本地小模型一起下好
- ✅ 默认自带官方音色，不折腾；安装程序版连朗读、麦克风与「断网也能聊」都开箱可用（本地小模型由向导按档位下载）
- ✅ 解压双击后，桌面上会多出一只 3D 小宠物陪你（默认开启，设置页里可随时关掉）

## 快速开始

1. **安装**：两种拿法——
   - **便携包**（`CX-A-portable-win64.zip`）：解压到任意目录，双击里面的 `CX-A.exe` 就能用；免安装、不写注册表，想卸载直接删掉文件夹即可；
   - **独立安装程序**（`CX-A-Setup-<版本>.exe`）：双击安装（默认装在用户目录，无需管理员），安装过程会自动装好**语音**（朗读与麦克风）与**本地推理运行时**，装完即用；卸载走系统「应用和功能」即可。
2. **首次引导**：跟随向导走完四小步——
   1. **看看你的电脑**：它会读一下你的内存、显卡和硬盘，告诉你「跑得动本地小模型」还是「更适合把思考交给云端」，并给一个推荐配置，你可以直接用，也可以自己改；
   2. **选云端服务商**：挑一个你信得过的，填入「云端钥匙」（在服务商官网申请即可）；暂时没有也能先跳过，以后再补；
   3. **选下载线路**：就一个问题——**国内（魔塔，推荐）**还是**海外（HuggingFace）**；选了国内，依赖和模型都从国内站点拿，一般更快更稳；
   4. **要不要现在就下本地小模型**：想让它断网也能聊就现在下（会显示进度，随时能停），不想下就点「以后再说」。
3. **开聊**：直接输入文字，或点语音按钮说话。
4. **（可选）交付电脑**：到设置页手动打开「电脑控制」；涉及电脑控制的高危操作前，它会先问你一句。
5. **（可选）想再跑一遍引导**：到设置页点「重新跑一遍新手引导」，可以重新挑下载线路、换模型大小，或者补下本地小模型。

> 想要更懂你？聊得越多，它记得越多。

## 隐私与安全

- 你的记忆**只存在本机**（除非你允许云端帮忙做深度整理）。
- 电脑控制**默认关闭**，必须你显式开启；高危操作执行前会先征求你同意，并留操作记录。
- 云端只负责「思考」，听与说都在本机完成。
- 你填的云端钥匙经加密保存在本地，不会上传。

## 常见问题

**Q：没显卡能跑吗？**
A：能。它把「想」交给云端，把「陪伴」留在本地；向导会按你的电脑给出合适的建议。

**Q：不想用云端可以吗？**
A：可以在设置里开启本地模式（需另下载本地小模型）；网络断了也有兜底，不会突然闭嘴。

**Q：下载老是失败、特别慢怎么办？**
A：在向导（或设置页的「重新跑一遍新手引导」）里把下载线路换成**国内（魔塔）**，依赖和模型都从国内站点拿，一般就顺畅了。下载中断也没关系，下次接着下，已经下好的部分不会白费。

**Q：本地小模型该下多大的？**
A：向导会按你的电脑推荐一档，直接用推荐的最省心。它提供四档，从约 0.5GB（最轻巧）到约 4.7GB（效果最好）：**电脑比较轻巧就选小的那档**，够用且不占地方；**内存和显卡都宽裕就选大的**，回答质量更好。默认推荐的那档约 1.1GB，普通家用电脑都带得动。

**Q：当时跳过了下载，现在想让它断网也能聊？**
A：到设置页点「重新跑一遍新手引导」，选好大小点下载就行；也可以直接开本地模式，它会在需要时提醒你补下。

**Q：管理面是干嘛的？**
A：管理它的「分身们」，或遥控家里那台重度版实例。普通用户用不到也不影响日常陪伴。

**Q：它能控制我的电脑，安全吗？**
A：默认完全关闭。只有你在设置里手动打开，且每一个高危指令都会先弹窗问你；任何时候可以在设置关闭，立即收回能力。
